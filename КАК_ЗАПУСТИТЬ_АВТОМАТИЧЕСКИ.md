# Запуск автоматического мониторинга через GitHub
### Для В.А. Новикова — пошаговая инструкция

Время на настройку: ~20 минут (один раз).
После этого агент работает сам, 1-го числа каждого месяца.

---

## Часть 1. GitHub — бесплатный хостинг для агента

### Шаг 1. Создать аккаунт на GitHub

1. Откройте [github.com](https://github.com)
2. Нажмите **Sign up** (верхний правый угол)
3. Введите email, придумайте логин (например `novikov-turner`) и пароль
4. Подтвердите email — придёт письмо

---

### Шаг 2. Создать репозиторий

1. На главной GitHub нажмите зелёную кнопку **New** (или значок `+` → **New repository**)
2. Заполните:
   - **Repository name:** `lit-monitor`
   - Выберите **Public** (обязательно — нужно для GitHub Pages)
   - Остальное не трогайте
3. Нажмите **Create repository**

---

### Шаг 3. Загрузить файлы агента

1. На странице нового репозитория найдите ссылку **uploading an existing file**
2. Распакуйте архив `lit-monitor.zip` на компьютере
3. Откройте распакованную папку `lit-monitor`
4. Выделите **все файлы и папки внутри** (Cmd+A на Mac)
5. Перетащите их в окно браузера
6. Внизу страницы нажмите **Commit changes**

> ⚠️ Важно: загружать нужно содержимое папки, а не саму папку.
> В репозитории должны быть файлы: `scripts/`, `.github/`, `README.md` и т.д.

---

### Шаг 4. Включить GitHub Pages (сайт с HTML-отчётом)

1. В репозитории нажмите **Settings** (вкладка вверху)
2. В левом меню найдите **Pages**
3. В разделе **Source** выберите: **Deploy from a branch**
4. Branch: **main**, папка: **/ (root)**  
   *(папка reports/ появится после первого запуска)*
5. Нажмите **Save**

---

## Часть 2. API-ключ Anthropic

### Шаг 5. Получить ключ

1. Зайдите на [console.anthropic.com](https://console.anthropic.com)
2. Зарегистрируйтесь (или войдите)
3. Слева: **API Keys** → **Create Key**
4. Назовите ключ `lit-monitor`, нажмите **Create Key**
5. **Скопируйте ключ** (начинается с `sk-ant-...`)
   > ⚠️ Показывается только один раз! Сохраните в надёжном месте.
6. Пополните баланс: **Settings → Billing** → минимум $5

---

### Шаг 6. Добавить ключ в GitHub

1. Вернитесь в репозиторий `lit-monitor` на GitHub
2. **Settings** → слева **Secrets and variables** → **Actions**
3. Нажмите **New repository secret**
4. Заполните:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Secret:** вставьте ключ `sk-ant-...`
5. Нажмите **Add secret**

*(Email-уведомления — опционально. Если хотите письма на почту,
добавьте ещё три секрета: `SENDGRID_API_KEY`, `EMAIL_TO`, `EMAIL_FROM`.
Инструкция по SendGrid — в разделе «Дополнительно» ниже.)*

---

## Часть 3. Первый запуск

### Шаг 7. Запустить вручную

1. В репозитории откройте вкладку **Actions**
2. Слева выберите **Monthly Literature Monitor**
3. Нажмите **Run workflow** → **Run workflow**
4. Появится зелёный индикатор — агент работает (3–10 минут)
5. Когда появится галочка ✅ — всё готово

### Шаг 8. Открыть отчёт

HTML-отчёт: `https://ВАШ-ЛОГИН.github.io/lit-monitor/reports/`

PDF-отчёт: в репозитории → папка `reports/` → файл `report_ГГГГ-ММ-ДД.pdf`

---

## Дальше — всё автоматически

Каждое 1-е число месяца в 10:00 МСК агент:
1. Ищет новые статьи (PubMed, 15 журналов, КиберЛенинка)
2. Анализирует через Claude, переводит аннотации
3. Удаляет галлюцинации
4. Публикует HTML и PDF
5. Отправляет письмо (если настроен email)

---

## Дополнительно: email-уведомления через SendGrid

1. Зарегистрируйтесь на [sendgrid.com](https://sendgrid.com) (бесплатно до 100 писем/день)
2. Создайте API-ключ в Settings → API Keys
3. Подтвердите адрес отправителя в Settings → Sender Authentication
4. Добавьте в GitHub Secrets:
   - `SENDGRID_API_KEY` — ключ SendGrid
   - `EMAIL_TO` — ваш email (куда получать)
   - `EMAIL_FROM` — подтверждённый адрес отправителя

## Частые вопросы

**Actions не запускаются автоматически** — GitHub иногда отключает
автозапуск в неактивных репозиториях. Зайдите на вкладку Actions
и нажмите **Enable GitHub Actions**.

**Ошибка в логе Actions** — нажмите на красный крестик, раскройте
шаг с ошибкой, скопируйте текст и напишите в Claude — разберёмся.

**Хочу изменить запросы** — в репозитории откройте
`scripts/monitor.py`, нажмите ✏️, найдите `PUBMED_QUERIES`,
добавьте нужные строки, нажмите **Commit changes**.
