# Инструкция по запуску агента мониторинга литературы
### Для В.А. Новикова — без программирования, шаг за шагом

---

## Что делает этот агент

Каждый понедельник в 10:00 по московскому времени агент автоматически:
1. Ищет свежие публикации в PubMed (26 запросов), российских журналах (6 лент) и КиберЛенинке
2. Для каждой найденной статьи ставит балл релевантности 1–10 и пишет резюме на русском языке
3. Формирует HTML-отчёт и PDF-отчёт, публикует их по ссылке в интернете
4. Всё это происходит само, без вашего участия

**Стоимость:** ~$0.10–0.20 за один еженедельный запуск (API Claude).

## Что нужно сделать один раз

### Шаг 1. Создать аккаунт на GitHub (если нет)

1. Зайдите на [github.com](https://github.com) → нажмите **Sign up**
2. Введите email, придумайте логин и пароль
3. Подтвердите email

---

### Шаг 2. Загрузить файлы агента на GitHub

1. На главной странице GitHub нажмите зелёную кнопку **New** (или **+** → **New repository**)
2. Название репозитория: `lit-monitor` (или любое другое — без пробелов)
3. Установите **Public** (публичный) — это нужно для GitHub Pages
4. Нажмите **Create repository**

Теперь нужно загрузить файлы. Самый простой способ:

5. На странице нового репозитория нажмите **uploading an existing file**
6. Распакуйте архив `lit-monitor.zip` на своём компьютере
7. Перетащите **все файлы и папки** из распакованной папки в окно браузера
8. Внизу нажмите **Commit changes**

> ⚠️ Важно: структура должна быть такой:
> - `.github/workflows/monitor.yml`
> - `scripts/monitor.py`
> - `scripts/make_pdf.py`
> - `requirements.txt`
> - `README.md`

---

### Шаг 3. Получить API-ключ Anthropic

Этот ключ нужен, чтобы Claude анализировал найденные статьи.

1. Зайдите на [console.anthropic.com](https://console.anthropic.com)
2. Зарегистрируйтесь или войдите
3. В меню слева выберите **API Keys**
4. Нажмите **Create Key**, назовите его, например, `lit-monitor`
5. **Скопируйте ключ** — он начинается с `sk-ant-...`
   > ⚠️ Ключ показывается только один раз! Сохраните его в надёжном месте.
6. Пополните баланс на $5–10 (хватит на несколько месяцев работы)

---

### Шаг 4. Добавить ключ в GitHub

1. Зайдите в ваш репозиторий на GitHub
2. Нажмите **Settings** (вкладка вверху справа)
3. В левом меню: **Secrets and variables** → **Actions**
4. Нажмите **New repository secret**
5. Имя: `ANTHROPIC_API_KEY`
6. Значение: вставьте ключ, скопированный в шаге 3
7. Нажмите **Add secret**

---

### Шаг 5. Включить GitHub Pages (сайт с отчётами)

1. В настройках репозитория (**Settings**) найдите раздел **Pages** (в левом меню)
2. В разделе **Source** выберите: **Deploy from a branch**
3. Branch: **main**, папка: **/reports**
4. Нажмите **Save**

Через 2–3 минуты ваш сайт с отчётами будет доступен по адресу:
```
https://ВАШ-ЛОГИН.github.io/lit-monitor/
```

---

### Шаг 6. Первый запуск (вручную)

1. Зайдите во вкладку **Actions** вашего репозитория
2. В левом меню выберите **Weekly Literature Monitor**
3. Нажмите **Run workflow** → **Run workflow**
4. Подождите 3–5 минут
5. Перейдите по адресу вашего сайта из шага 5 — там появится отчёт

## Как пользоваться отчётом

**HTML-версия** (сайт): статьи разбиты на три секции по релевантности. Зелёный кружок (7–10) — читать обязательно. Жёлтый (4–6) — просмотреть. Серый (1–3) — можно пропустить.

**PDF-версия**: автоматически создаётся вместе с HTML. Скачать можно с сайта или напрямую из папки `reports/` репозитория.

**Цвета бейджей:**
- 🟦 Тёмно-синий — PubMed
- 🟣 Фиолетовый — российские журналы (Турнера, Приорова и др.)
- 🔴 Красный — КиберЛенинка

## Расписание проверки журналов

Агент умный: ежемесячные журналы проверяются каждую неделю, квартальные — только около даты выхода номера (±3 дня). Это экономит ресурсы и не пропускает выпуски.

| Журнал | Периодичность |
|--------|--------------|
| Dev Med Child Neurol, J Pediatr Orthop и др. | Ежемесячно |
| ОТВХДВ Турнера, Вестник Приорова | Ежеквартально (март, июнь, сент, дек) |
| КиберЛенинка, Gait & Posture, Cochrane | Каждую неделю |

## Как изменить поисковые запросы

Если хотите добавить или убрать тему поиска:

1. В репозитории откройте файл `scripts/monitor.py`
2. Нажмите иконку карандаша ✏️ (редактировать)
3. Найдите раздел `PUBMED_QUERIES = [` (примерно строка 30)
4. Добавьте новую строку в кавычках, например:
   ```
   "tendon transfer reinnervation pediatric",
   ```
5. Нажмите **Commit changes**

## Частые вопросы

**Агент не запустился автоматически** — проверьте вкладку Actions. GitHub иногда отключает автозапуск в репозиториях без активности. Зайдите в Actions → включите workflows.

**В отчёте мало статей** — норма для «тихих» недель. Главные журналы квартальные, в промежутке PubMed даёт 20–60 статей.

**Отчёт на сайте не обновился** — подождите 5–10 минут после запуска. GitHub Pages обновляется с задержкой.

**Хочу изменить расписание** — в файле `monitor.yml` строка `cron: "0 7 * * 1"` означает «каждый понедельник в 10:00 МСК». Для изменения дня: 1=пн, 2=вт ... 7=вс.
