# Как пользоваться агентом без оплаты API

Весь процесс занимает 5 минут раз в неделю.

---

## Один раз: установить Python

Python — бесплатная программа. Если уже установлен, пропустите.

1. Зайдите на [python.org/downloads](https://www.python.org/downloads/)
2. Нажмите большую жёлтую кнопку «Download Python»
3. Запустите скачанный файл, установите
4. **Важно при установке:** поставьте галочку «Add Python to PATH»

---

## Один раз: настроить папку

1. Распакуйте архив `lit-monitor.zip` в любую удобную папку,
   например `C:\Документы\lit-monitor\` или `~/lit-monitor/`
2. Больше ничего устанавливать не нужно

---

## Каждую неделю: 3 шага

### Шаг 1 — Запустить сбор статей

**На Windows:**
- Откройте папку `lit-monitor`
- Зажмите Shift и кликните правой кнопкой мыши на пустом месте
- Выберите «Открыть окно PowerShell здесь»
- Введите команду и нажмите Enter:
  ```
  python scripts/collect_only.py
  ```

**На Mac:**
- Откройте «Терминал» (найдите через Spotlight: Cmd+Space → «Терминал»)
- Введите `cd ` (с пробелом после cd), перетащите папку `lit-monitor` в окно терминала, нажмите Enter
- Введите команду и нажмите Enter:
  ```
  python3 scripts/collect_only.py
  ```

Подождите 2–4 минуты. В папке `reports/` появится файл
`collected_ГГГГ-ММ-ДД.json`

---

### Шаг 2 — Отправить файл в Claude

1. Откройте [claude.ai](https://claude.ai) — вы уже там зарегистрированы
2. Начните новый чат в вашем **Проекте** (чтобы Claude помнил контекст)
3. Прикрепите файл `collected_ГГГГ-ММ-ДД.json` через кнопку скрепки 📎
4. Напишите:

> Проанализируй эти статьи. Для каждой: оцени релевантность 1–10,
> переведи аннотацию на русский, выдели 2–3 тезиса на что обратить
> внимание. Сделай PDF-отчёт.

---

### Шаг 3 — Получить PDF

Claude проанализирует статьи и отдаст готовый PDF.
Всё на русском, с тезисами и переводами.

---

## Когда будет время — автоматизировать

Когда разберётесь с оплатой (Anthropic принимает крипту, карты
банков Армении/Казахстана), просто добавьте API-ключ в GitHub Secrets
и агент начнёт работать полностью автоматически. Код уже готов.

---

## Если что-то пошло не так

**«python не является внутренней командой»** — Python не добавлен в PATH.
Переустановите Python с галочкой «Add Python to PATH».

**Скрипт завис на «PubMed:...»** — нет интернета или PubMed временно
недоступен. Подождите минуту и попробуйте ещё раз.

**Файл collected_*.json пустой или маленький** — нормально для «тихих»
недель. Значит за последние 35 дней вышло мало новых статей по теме.
